# KrakenRoot CTF

## Overview

KrakenRoot is a custom Capture The Flag (CTF) challenge focused on practical penetration testing techniques including enumeration, OSINT, web exploitation, password cracking, SSH access, and privilege escalation.

## Skills Demonstrated

* Network Enumeration
* FTP Enumeration
* Steganography
* OSINT Investigation
* Web Enumeration
* Password Cracking
* SSH Authentication
* Linux Privilege Escalation

## Tools Used

* Nmap
* FTP
* Gobuster
* Hydra
* John the Ripper
* Steghide
* SSH

## Attack Path

1. Network Enumeration
2. FTP Anonymous Access
3. ZIP Password Cracking
4. Steganography Analysis
5. OSINT Investigation
6. Directory Enumeration
7. Credential Discovery
8. SSH Access
9. User Flag Retrieval
10. Privilege Escalation
11. Root Flag Discovery
